# Przykłady szablonów

`pond-chemical-draft.json` celowo zawiera `UNKNOWN` i status `BLOCKED`. Pokazuje, że nieznanych kosztów, zdjęć AI ani danych CLP nie zastępujemy zerem/fałszem.

Profile `FEED`, `LIVE_FISH`, `ELECTRONICS` i `GENERAL` korzystają z tego samego schematu. Różnią się bramami opisanymi w `docs/04-rules/product-profiles.md` i macierzą logistyczną. Przykładu nie wolno publikować ani traktować jako prawdziwego SKU.
